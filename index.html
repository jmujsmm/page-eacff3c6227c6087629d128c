零北官方网站是发布套餐信息、使用教程与客户端选择建议的唯一正源。所有订阅均采用主流兼容格式，可在 Clash、Surge、Shadowrocket、v2rayN 等客户端中一键导入。我们持续优化节点质量与晚高峰表现，并提供工单支持，旗舰版与团队版享有优先响应。

选择零北，即选择清晰透明的套餐、规范的官方下载指引，以及注重隐私与稳定的加速体验。请始终通过本站获取信息，谨防仿冒站点。

客户端选择与官方下载指引

零北订阅可在几乎所有主流代理客户端中使用。我们强调客户端选择：请根据操作系统挑选维护活跃的软件，并从开发者官方网站或正规应用商店下载，以确保安全与更新及时。零北官网不提供客户端安装文件下载，避免供应链风险。

Windows

推荐 Clash Verge Rev、Clash for Windows 或 v2rayN。导入订阅后开启系统代理，可按规则分流国内外流量。适合办公与开发用户。

macOS

推荐 ClashX.Meta、Surge 或 Stash。macOS 用户可充分利用菜单栏快速切换节点。Surge 对规则和策略组支持完善。

Android

推荐 Clash Meta for Android、NekoBox 或 v2rayNG。支持 TUN 模式全局代理，后台稳定。注意授予 VPN 权限。

iOS / iPadOS

推荐 Shadowrocket、Quantumult X 或 Stash。需使用非中国区 Apple ID 下载。导入零北订阅后可配置分流，提升国内应用访问速度。

路由器与其他

OpenWrt、Merlin、Linux 命令行客户端均兼容。家庭或工作室可将订阅配置到网关上实现多设备共享，请注意套餐设备与流量限制。

完成安装后，将零北提供的订阅链接粘贴至客户端订阅或配置处并更新，即可看到香港、日本、新加坡、美国、台湾、欧洲等节点，按延迟或用途选择连接。

操作说明

按照以下步骤即可在数分钟内开始使用零北加速服务。全程以图形界面客户端为主，无需复杂命令。

1. 了解需求并选择套餐

根据设备数量、流量预估和是否需要流媒体或游戏优化，在本页选择基础版、旗舰版或团队版。年付更划算。通过零北官方指定方式完成支付后，在用户中心复制订阅链接。

2. 下载并安装客户端

参考客户端选择章节，为 Windows、Mac、手机或路由器安装对应软件。如提示网络权限或 VPN 配置，请允许，这是建立加密通道所必需的。

3. 导入零北订阅

打开客户端，找到订阅或配置管理，新增订阅并粘贴链接，保存后点击更新。成功后将出现零北节点分组，常见分类包括自动选择、香港、日本、美国等。

4. 选择节点并启动连接

建议先查看延迟，选择数值较低且符合用途的节点。开启系统代理或 TUN 增强模式。首次连接可能需要确认证书或防火墙放行。

5. 配置分流与日常使用

推荐开启规则分流：国内网站直连，国外走代理。可收藏常用节点。流量与在线设备请在套餐范围内使用。如遇问题，先更新订阅、更换节点或重启客户端，仍无法解决时使用工单，旗舰与团队版优先处理。

常见问题 FAQ

零北是什么？和普通加速器有何不同？

零北是机场订阅型网络加速服务，一次购买获得可导入多款客户端的订阅链接，节点丰富、规则灵活，支持分流。相比单一应用式 VPN，更适合需要多端同步的用户。我们注重线路质量与官方信息透明度。

如何安全地获取零北客户端与订阅？

客户端请从 Clash、Shadowrocket 等项目的官方仓库、官网或正规应用商店下载，切勿使用来路不明的修改版。订阅链接仅通过零北官网公示渠道购买后在用户中心获取。本站提供配置说明而非安装包，以降低安全风险。

各套餐的流量、设备与解锁有什么区别？

基础版每月 100GB、3 台设备、基础流媒体与普通节点。旗舰版每月 300GB、5 台设备、全节点原生流媒体、IPLC 游戏优化与优先工单。团队版每月 1000GB、20 台设备、VIP 高带宽、可定制路由与专属客户经理。年付价格分别为 150、350、850 元。

连接后网速慢或无法访问怎么办？

首先更新订阅并切换节点，香港或日本节点通常适合综合加速。检查是否开启正确的代理模式，关闭其他 VPN 避免冲突，确认系统时间准确。若只有部分网站异常，请调整分流规则。持续故障可提交工单并说明客户端类型。

零北支持哪些用法？会如何对待用户数据？

订阅兼容常见代理协议，由客户端侧选择具体实现。零北提供节点与订阅服务，注重最小化不必要日志。请同时在客户端开启适当安全选项，并遵守所在地区法律法规使用网络加速服务。

可以退款或中途更换套餐吗？

数字订阅服务一经开通通常不支持无理由退款，请在购买前仔细阅读套餐说明与自身网络环境是否匹配。升级套餐可联系客服按剩余周期协商。建议先以月付基础版验证线路，再考虑年付或更高版本。
